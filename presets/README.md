# 可复现的字库与变形预设

参数来自2026-11-09本机软件保存的配置；按白名单摘取字体相关文件，没有导出整套机器配置。它们是配置快照，不含字形文件。

| 文件 | 作用 |
|---|---|
| FontsDialogData.json | 字库名称及抽取权重，6/4/2/0；第四套保留原记录但权重为0 |
| FontsSetData.json | 原始变形字段及其保存值 |
| text-page-info.json | 已使用的原生文字对象参数，生成脚本据此补区域尺寸 |

## 变形值一览

| 原字段 | 保存值 | 阅读提示 |
|---|---|---|
| randomFontSize | [0.95, 1.0] | 字号比例范围 |
| randomSpace | [0.85, 1.1] | 字间距比例范围 |
| randomRotate | [-5.0, -5.0] | 两端同为-5；原样保留，不擅自改成对称区间 |
| randomXScale | [0.75, 1.2] | 横向拉伸范围 |
| randomYScale | [0.85, 1.1] | 纵向拉伸范围 |
| randomY | 0.02 | 垂直扰动字段原值；不能直接当成毫米 |
| randomFirstPos | 0.0 | 行首位置扰动字段原值 |
| baseLine | 1.0 | 全局基线字段原值；与对象pageInfo.baseLine区分 |
| widthAdd / tabWidthAdd / spaceWidthAdd / simple | 0.0 | 原样保留的其他字段 |
| chars | ，,.。 | 标点字段原值 |

这些是按字段名解释的配置值，未通过源码证明所有内部单位和算法。软件界面显示与实际笔迹优先，不把“随机”字段名理解成每个字都必然变化。

## 如何使用

先在自己的软件里保存备份，通过字体/变形界面核对并填写对应值。不要把这些文件当作完整软件导入包直接覆盖用户目录。导入原生模板后还要检查各对象fontPath；权重与变形设置可能不随模板一起加载。

当前文字预设fontSize=100、lineGap=6.6、lineGapOffset=0.3、space=1。它对应本次认可的实际大小，不代表所有软件里的100pt，也不能在已经放大的模板上再乘1.5。

字号浮动和拉伸不等于改善数字整齐度。连续数字要看真实预览和小样；不要用缩矮文字框来假定能限制浮动。

数学图稿选字：Ink Free主体，Segoe Print的6和7，1使用单竖线。仓库不分发这两套字体或派生混合字体。图形模式案例为边缘图＋细化，仍需逐稿核对实际毫米范围。
