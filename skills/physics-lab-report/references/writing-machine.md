# 写字机：从版面到落笔

本流程来自颂博士写字机和奎享雕刻的实际操作。参数是案例预设；设备幅面、软件版本、纸张与许可要在当前任务检查。

## 1. 统一物理坐标

- 每个物理面独立文件，一面可有多个文字对象。跨面章节仍分面，不依赖机器自动翻纸。
- 以印刷外框左上角交点为O，坐标向右、向下，单位毫米；不是纸张左上角或第一个居中字符。
- 空白底板保持实测外框尺寸，正文左右通常内缩约3mm。不要缩小整个底板来留白。短身份字段放对应格中间，不能压住印刷标题。
- 栏目独立定位，不靠累计空行；公式/图/粘贴区先留矩形，再排正文。两字缩进只用一种方式，避免全角空格与首行缩进叠加。
- 校准公式：x_mm=(x_px-Ox_px)×框宽_mm/框宽_px；y同理。照片倾斜时先校正四角。相对估算可以接受，不声称像素估算等于精密测量。
- 字号先按实写小样确定，再统筹各面。已放大1.5倍不能再乘1.5；某一行实写偏上，局部修正该对象，先排除页面尺寸缓存问题。
- 按阅读关系紧凑安排正文与图表，先保证图表尺寸清楚，检查小图和过大段距造成的空洞；内容齐全可留白，不凑字数。已上纸或已粘贴的区域以实物为准，不为排版整齐要求重写重贴。

## 2. 字库、公式和图形

- 可选案例：blood8真迹/真迹2/真迹3，6∶4∶2。保留用户自己的最新选择。每个文字对象的fontPath也要同步，不能只改全局后假定全部生效。
- 变形和权重可存在全局配置，JSON文字对象保存的是另一组参数。不要承诺一个模板封装所有设置。
- 本机fontSize=100时，lineGap也影响字形实际大小，不能只当空白行距。改字号后检查换行、完整数字和段尾。
- 连续数字上下跳动可先检查实际字形；没有独立开关的证据时，不承诺缩矮文字框就能限制浮动。
- 中文和图注用原生字库；公式用正常分式、根号和上下标。图内必要字母/数字/单位保留，汉字不能换成微小印刷截图。
- 数学字体案例：Ink Free为主体，6/7取Segoe Print，1为无顶撇和底衬的竖线。这里只分享选择方法，不要求安装或分发混合字体。
- 简图根据讲义核对物理关系后重画。避免装置照片、复杂PPT截图；不为了仿手绘给直线或圆弧添加随机歪曲。
- 先确定用户选择的绘图分工。本机用户偏好机器画横竖直线为主的尺规简图，复杂圆弧、圆盘和立体装置留给本人手画；这类图只预留区域，并说明位置、必标量和讲义页码。该选择不改变公式机写、拟合图打印安排；其他使用者可选自己的分工。
- 说明紧接相应公式，按阅读顺序自然分组，不把不同用途的公式无连接地铺成三列，也不为填满区域扩大间距。
- 同面同逻辑区的相邻图/式可以合成大图，减少定位。不要强拉远处图形合并；两者之间的中文保留原生对象，并在图稿中留出其位置。

## 3. 图稿的起点与实际尺寸

- 第一处墨迹可能远离O。软件可能自动裁掉空白；可在O设置约0.5mm短直角定位标记，并保留处理白边，更新后检查标记没被去噪移除。
- 如果左/上白边被裁去，图稿新原点在原O向右/下偏移相应距离，不能把偏移反向扣除。以软件实际行为核验。
- 实写比较中，边缘图＋细化比实心图细，尤其适合数字。它仍可能描轮廓或重复走线，不等于单笔中心线。
- 比较模式共用同一源图、同一内容、实际尺寸和字体，不能拿两份不同内容对照。小样应包含分式、数字、特殊字母和实际会用的简图。
- 每次切模式、导入、重启：核对文件/面号、模式/细化、提交缩放、更新、检查红色毫米范围。旧缩放值不能跨模式或分辨率直接套用。
- 本机显示过纵X横Y。核验起点到最远墨迹的完整范围，包括空走距离。曾因缩放恢复1生成约400—600mm任务而越界。

## 4. 原生模板

- 从本机真实保存的模板确认结构。案例顶层宽高为厘米；文字对象x/y/width/height为96dpi像素；pageInfo宽高为毫米。不同版本先比对保存样本。
- 导入顺序：表格模式“模板→打开”同面JSON → “文件→打开”同面空白PNG → 核对实测尺寸 → 更新 → 检查字库、换行和段尾。
- 模板打开会清掉底图，需要恢复。一个模板能复用多个区域的位置，不需要逐字摆放；它不保存纸张物理位置。
- 页面尺寸标签正确而底板仍像A4时，本机通过先选A5再切回目标尺寸刷新成功。先修缓存，不为此改正确的坐标。
- 更新报错时保留模板，重新载入并设尺寸，必要时重启。400dpi报错、250dpi成功只是一次案例，不当作通用像素上限。
- PDF弹窗超屏时可改清晰PNG。底板要清晰，照片用于校准，不能把模糊整页照片当最终预览。

## 5. 同面续写、并行准备与补救

- 顺序：本面文字/图注 → 本面公式/简图 → 翻面。“下一页”先检查本面有没有剩下的图，减少翻纸和重复对位。
- 在本机确认正常写完会回起点，且纸未移动、原点未改时，同面后续任务沿用起点。有用户连续书写授权即可检查后启动，不重复询问。
- 换面、移动纸张、撞边、中止后重新核对定位；不要随意点机械原点/设置原点试错。正在运行的任务不重复点书写。
- 可在已授权任务运行中准备下一份预览。记录切模式、导入、更新各自是否发生在运行期间，观察进度和异常；不要把一次切模式成功说成整套并行操作已验证。
- 现有实测覆盖运行中切模式、导入，运行中更新仍未完整覆盖。新任务开始须等上一个任务结束，换面还需用户固定纸张。
- 已上纸排版要补救：固定旧文字/公式坐标，找空隙，新增短说明；另存“仅补写”模板。完整叠加预览检查碰撞，发送机器的文件只能含新增对象。记录执行状态，避免叠写。

## 6. 打印剪贴与最终检查

- 老师允许时，密集数据表和拟合图按实际大小打印；助手直接统筹贴位，文字模板保留同一矩形。
- 打印载体上写明：目标报告面与栏目、块宽高、裁切线、顶部方向、块左上角距外框O的x/y。说明放裁切块外，附校准线，按100%打印。
- A4剪贴载体不是额外报告面。不得因打印方便自行增加报告附页。
- 区分内容包围框、裁切框和报告纸预留区：裁切框含剪刀余量，预留区容纳整个剪下块。标注裁切框外尺寸，粘贴坐标指剪下块左上角，不是内缩后图表的起点。
- 裁切虚线内缘距全部文字、数字、图表线、图例及上下标的最外侧墨迹至少3mm净白边，操作说明与裁切标记不进入白边。不能只按文本框或PDF页面边界判断，也不得为了塞下内容删除这层余量。
- 尚未上纸时先加足白边，再安排预留区。已上纸且贴位固定时保持剪下块尺寸与坐标，只在框内等比内缩内容；检查最小数字、下标和图例的可读性。难读时重排或拆到现有可用区域，不持续缩字，不缩放A4载体、校准线及定位说明。
- 最终PDF逐页渲染，核对四边白边、标题、末行、图例和上下标；同时检查整个剪下块不盖住报告纸印刷标题或已写正文。边界计算不能代替视觉检查，完整预览须同步反映新内容尺寸。
- 交付到桌面或传手机时，仅提供当前带裁切说明的打印载体，不混入图表源PDF、底板或完整预览。更新前将旧稿留在工作区，替换指定副本后比对哈希，提醒用户重新传新版；未实际传输不声称手机副本已更新。
- 检查原生文字、公式图稿、完整预览和剪贴图一致；保留已上纸版本，修订另存。只展示预览时不启动。
- 完成状态分别记录“生成/导入/更新/启动/软件完成/实物效果”，旧100%不能证明新任务完成。
