# 中文审稿

把最终正文连起来读一遍，逐项修改，再与公式、数值和图表核对。

- 采用学生实验报告的口吻，直接写关系、计算、结果和物理原因。删除“根据用户提供”“数据中要求”“skill中要求”等编辑过程。
- 用实际偏差与对应误差机制代替空泛提醒。不把每段结尾写成“仍需确认”“不能保证”。真正未完成的计算放工作记录，不能靠措辞掩盖。
- 保留科学限定、不确定度和测量异常。可能的误差来源仍然是可能，不能写成已经观察到的事实。
- 删除重复、夸大、泛化的意义和没有信息的总结。仪器、数据、单位、符号、条件不能因润色被丢掉。
- 复核每句话是否与实验有关，推导的先后和因果是否成立。重排内容后同步更新模板与完整预览，检查软件中的确是新正文。
