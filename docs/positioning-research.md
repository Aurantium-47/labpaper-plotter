# 把时间还给大学生活：调研与灵感来源

调研日期：2026-11-09。围绕三个问题检索：同类 skill 怎样描述需求；已有软件把纸面书写做到哪一步；关于大学时间、自主学习与低价值劳动，有哪些值得借鉴的观点。

## 我们选择的定位

**让 AI 看资料、做排版，让机器动笔，把时间还给大学生活。**

我们已在大物报告中跑通资料整理、实物版面安排与机器书写。当前开源内容是一套工作流程及其 skill、参数和模板工具，大物是首个应用场景。项目要解决的是重复抄写、反复定位和重新排版占用时间的问题。

## 六个相关项目怎样说

以下为作者 README／仓库说明中的能力声明，调研没有安装或实测这些项目。这里只比较公开定位和交付形式。

| 项目 | 作者公开介绍的重点 | 对我们的启发 |
|---|---|---|
| [Inko](https://github.com/pretend1111/inko-skill) | 从内容生成标准二维手写图片/PDF，提供纸张、字形、间距等控制 | 写清输入与输出，展示具体用途。其当前 README 与 About 的旧描述有差异，以正文为准 |
| [ai-handwriting-skill](https://github.com/yuan-fd/ai-handwriting-skill) | 用手写参考样本和图像生成能力，把电子答案、文字及报告转成手写页面与扫描风格 PDF；仓库简介直接点出抄写作业需求 | 读者先关心眼前有什么麻烦，再关心用了什么技术 |
| [paperAgent](https://github.com/Devil-Galois/paperAgent) | 仓库简介写水课论文，README 展开为从需求、资料到草稿和 DOCX 的分阶段写作流程 | 鲜明的需求表达要有可执行流程承接；不能只抄简介就推断实际能力 |
| [draw-your-font](https://github.com/danilo-znamerovszkij/draw-your-font) | 从手写字母照片生成字体文件 | 用具体的起点和结果介绍项目，读者容易理解 |
| [AutoJotter](https://github.com/jaemuzzin/AutoJotter) | 将纯文本转成供绘图机使用的单线书写 G-code 或 SVG | 文本到真实笔运动已有实现；我们的价值应落在场景整合与复用经验上 |
| [Maliang](https://github.com/hjk41/Maliang) | 在书页照片上编辑文字和图画，通过 USB 写字机输出；还公开了 Agent 接口及校准流程 | 是直接相关的纸面排版与实机工具。其 README 区分历史试写与新版待验收范围，不能将全部声明当成已验证结果 |

检索发现既有电子手写生成，也有真实写字机工具。因此，我们强调自己已经跑通的组合：**资料整理、实际纸张布局、原生中文、公式简图、同面书写和模板复用。** 这里没有据此做首创或无竞品判断。

## 值得采用的观点与短引文

### 时间由自己支配

《上海交通大学生存手册》原文：

> 我们真正投下的有价值的筹码，是时间。

来源：[《正确地浪费剩下的时间》](https://github.com/SurviveSJTU/SurviveSJTUManual/blob/master/li-zhi-pian/zheng-que-di-lang-fei-sheng-xia-de-shi-jian.md)。同书另有[《总有更值得做的事情》](https://github.com/SurviveSJTU/SurviveSJTUManual/blob/master/li-zhi-pian/zong-you-geng-zhi-de-zuo-de-shi-qing.md)，主张考虑不同事务的时间价值。

采用的思路：学生应当有选择时间用途的空间。原书一些关于成绩、课程与休闲的评价很绝对，也有年代和个人经历背景；我们没有把它们整体搬进项目立场。运动、交朋友和休息也可以是省下时间的去处。

### 自己想做的项目，值得留下时间

Paul Graham 在 *A Project of One’s Own* 中写道：

> There is something special about working on a project of your own.

自译：做一个属于自己的项目，会有一种特别的感受。原文继续讨论主动选择工作时的兴奋与投入，也承认学校作业有时能成为这样的项目。[原文，2021 年 6 月](https://paulgraham.com/own.html)

采用的思路：把自主项目写成具体的时间去处。这里引用的是作者的观点，并非他对本项目或写字机的推荐。

### 学到东西和拿到评价，不总是一回事

Paul Graham 在 *The Lesson to Unlearn* 中批评学校评价可能诱导学生围绕分数优化，偏离理解本身。这是对文章观点的转述。[原文，2019 年 12 月](https://paulgraham.com/lesson.html)

同文的 Hacker News 讨论中，用户 knzhou 从设计物理测验的角度指出，题型更换仍可能被应试策略消解，规模化考核本身很难。这里选取该条顶层长评论，并阅读了其下部分回复，未遍历整个讨论；它提供了不同角度，不能代表评论区共识。[评论原文](https://news.ycombinator.com/item?id=21731854)

采用的思路：表达对形式性劳动的反感，同时让内容核对、原理理解和数据分析保留应有的位置。

### 好课程值得主动寻找

[CS 自学指南前言](https://csdiy.wiki/)讲述作者从早期专业课学习的挫败，到通过 CS61A 找到充实、自主学习体验的经历。这里是对作者个人经历的转述。

采用的思路：减少重复劳动后，可以把时间交给自己认可的课程和项目。我们借鉴这种主动选择，不把所有课程都归为无用。

### 水课背后也有制度问题

[《你大学里讨厌的“水课”，老师也烦》](https://edu.ycwb.com/2023-12/14/content_52383363.htm)讨论教学考核、科研压力、学生选课激励和时间负担。所读页面是金羊网 2023-12-14 转载，页面标注来源央视网；未将转载算作独立的第二份证据。

采用的思路：把需求说具体——减少低价值重复劳动，给学生更多可支配时间。该报道同时呈现了课程评价的复杂性，不能拿来证明所有大学课程都无用。

## 可直接使用的原创文案

以下为本项目原创表达，受上述讨论启发，不是名人原话。

**首页标题：** 把时间还给大学生活。

**流程介绍：** AI 看资料、做排版，写字机动笔。我们已经把这条流程跑通了。

**鲜明一点：** 水课已经占了时间，机械抄写就别再占一遍。

**生活一点：** 机器接着写，你的晚上可以另有安排。

**项目介绍：** 从一份大物报告开始，我们把 AI 整理资料、纸面排版和写字机串成了可复用的流程。把反复抄写和调格式的时间省下来，留给自己想学的课、想做的项目，以及大学生活本身。

**发布短文：** 我们把 AI 和写字机接上了。给它资料和实际纸张尺寸，助手整理内容、安排文字和公式，再通过软件让机器动笔。大物报告已经跑通，字库权重、变形设置和模板工具也一起开源。少一点为了交差的机械抄写，多一点自己安排的大学生活。
